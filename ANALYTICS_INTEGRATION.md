# Vercel Web Analytics Integration

This document describes the Vercel Web Analytics integration for the n8n Enterprise Workflows project.

## Overview

Vercel Web Analytics has been integrated into this project to provide real-time insights into page views, visitor behavior, and performance metrics.

## Integration Methods

This project demonstrates **two approaches** for integrating Vercel Web Analytics:

### 1. Direct Script Tag (Plain HTML) - Used in `index.html`

The simplest method for plain HTML sites. No package installation needed for this approach:

```html
<!-- Vercel Web Analytics - Direct Script Tag Integration -->
<script>
    window.va = window.va || function () { (window.vaq = window.vaq || []).push(arguments); };
</script>
<script defer src="/_vercel/insights/script.js"></script>
```

**Advantages:**
- No build step required
- Works immediately in any HTML file
- Minimal setup

### 2. Package-based Integration - Example in `app.js`

For JavaScript frameworks and applications, use the `@vercel/analytics` package:

```javascript
import { inject } from '@vercel/analytics';

// Initialize Vercel Web Analytics
inject();
```

**Advantages:**
- Programmatic control
- Better integration with modern frameworks
- TypeScript support

## Installation

The `@vercel/analytics` package has been added as a dependency:

```bash
npm install @vercel/analytics
```

**Dependencies installed:**
- `@vercel/analytics@^1.3.1` - Vercel Web Analytics SDK
- `http-server@^14.1.1` (dev) - For local development

## Usage

### Tracking Custom Events

The integration includes examples for tracking custom events:

```javascript
// Track custom events (available after analytics loads)
if (window.va) {
    window.va('event', { 
        name: 'cta_click', 
        data: { button: 'github' } 
    });
}
```

### Running Locally

To test the integration locally:

```bash
npm run dev
```

Then visit `http://localhost:3000` to see the site with analytics.

## Important Notes

1. **Client-side Only**: The `inject()` function must run on the client side, not during server-side rendering.

2. **No Route Support**: The basic `inject()` function does not include route change tracking. For single-page applications with routing, you'll need to manually track route changes:

   ```javascript
   // Track route changes manually
   if (window.va) {
       window.va('pageview', { path: window.location.pathname });
   }
   ```

3. **Automatic Tracking**: The script automatically tracks:
   - Page views
   - Unique visitors
   - Referrer information
   - Device and browser data

4. **Privacy**: Vercel Analytics is privacy-friendly and GDPR-compliant. No cookies are used, and no personal data is collected.

## Vercel Deployment

When deployed to Vercel, analytics will automatically start collecting data. The `/_vercel/insights/script.js` path is served by Vercel's edge network.

To enable analytics in your Vercel project:

1. Deploy this project to Vercel
2. Go to your project settings in Vercel Dashboard
3. Navigate to "Analytics" tab
4. Enable Web Analytics
5. Data will start appearing within minutes

## Framework-Specific Integrations

For specific frameworks, refer to Vercel's documentation:

- **Next.js**: Use `@vercel/analytics/next`
- **React**: Use `@vercel/analytics/react`
- **Vue**: Use `@vercel/analytics/vue`
- **Svelte**: Use `@vercel/analytics/svelte`

Example for Next.js:

```javascript
import { Analytics } from '@vercel/analytics/react';

function App() {
  return (
    <>
      <YourApp />
      <Analytics />
    </>
  );
}
```
